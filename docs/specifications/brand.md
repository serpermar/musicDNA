# Identidad visual

## Principios

Moderna, tecnológica y musical. Sensación de descubrimiento, creatividad y personalidad.

## Paleta

| Uso              | Color            | Hex       |
| ---------------- | ---------------- | --------- |
| Fondo principal  | Dark             | `#0B0B14` |
| Superficie       | Dark surface     | `#151525` |
| Primario         | Morado eléctrico | `#8B5CF6` |
| Secundario       | Azul intenso     | `#2563EB` |
| Complemento      | Rosa             | `#EC4899` |
| Complemento      | Naranja          | `#F97316` |
| Texto            | Casi blanco      | `#F8FAFC` |
| Texto secundario | Gris claro       | `#A5B4FC` |

## Tipografía

- **Inter**: interfaz y texto.
- **Plus Jakarta Sans**: titulares y cifras destacadas.

## Componentes y estilo

- Dark mode como tema principal.
- Gradientes morado → azul y rosa → naranja para acentos.
- Tarjetas visuales con bordes sutiles y sombra suave.
- Gráficos interactivos para afinidades y comparaciones.
- Microinteracciones y animaciones suaves (sin excesos).
- Diseño responsive: misma identidad en escritorio y móvil.

Los tokens canónicos están en `packages/config/brand.json`.
